# 分层控制与输出边界

Sol输入已观察地图、房间实体、血量资源、构筑、机制摘要及可用选择，输出路线、道具/资源取舍、目标和条件性意图。计划经校验后由本地合同执行器落实。提前规划需要在当前状态下重新验证，不拥有额外消费权限。

JEV战术接口输入最多5个目标、局部危险及当前计划，输出target与posture。姿态为range、clockwise、counterclockwise、disengage；两部分置信度独立检查。最短请求间隔2秒，超过4秒/120更新的回复过期，意图最多保留3秒/90更新。range额外偏置为0，其余偏置限幅±8。

本地控制在网络请求期间继续运行，从9种移动和5种射击中筛风险、评分，再经安全检查。近身威胁可覆盖JEV目标。当前hybrid不是远程逐帧按键控制。

all模式的JEV目标与记忆模块仍是实验分支。记忆为一次候选评分及预算筛选，未完整复现Jev-Mem多轮检索或关系图。没有新训练权重或在线RL。

日志的“模型已返回”“部分字段被采用”“实际动作改变”“游戏效果变好”是不同证据层次。`input.source`标签不能单独证明该动作因JEV而变化。
