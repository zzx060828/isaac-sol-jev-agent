# 冻结原型评估摘要（2026-09-25）

对象：公开整理前的冻结原型，195个登记源码文件；Repentance、Magdalena、Normal，保留EID等模组。每局配置900秒WSL单调时间，墙钟输入跨度约15分半。临时关闭影响起始道具一致性的Betterish Start后，对比tactics与off；两组均保留Sol和同一套本地控制。

12个登记案例，10个实际玩法，4组匹配开局的完整玩法日志，3组完整录像。公开仓库仅保留聚合摘要和必要fixture；原始私人运行日志、存档、录像及完整冻结快照未上传，因此这些结果不是一个随仓库附带全部证据的独立复现包。

六局JEV共1056请求、924次接收意图、105丢弃、25错误、2次未记录终态。实际采用844次姿态，全部range；4次disengage响应的姿态字段未通过置信度门槛。1931个精确合格战斗采样中，移除当前意图会改变107个动作（移动59、射击82，有重叠）。这是单状态行为影响，不是收益或胜率。

请求、网络条件、后续随机轨迹和Sol输出不完全相同；样本不足，不能简单累加伤害判断谁更强。结论：当前JEV战术不是硬依赖，稳定收益未获证明，保留为可选实验模块。该结论不覆盖all模式的目标/记忆分支，也不证明JEV普遍无用。

主要待修问题：障碍后射击位置搜索、地刺旁局部停滞、Stoney机制与风险代价不一致、规划方案超出执行器支持范围、无效字段和网络错误引起的重复等待。

本公开整理版修改了路径解析、示例配置及文档，完成离线回归；没有为整理版重新进行整批游戏对照，不宣称实机收益变化。
